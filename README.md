Entry for the [make.fun](https://make.fun/c/u-suroto-last-words-of-a-dying-ai-dfd95af6) competition **Last Words of a Dying AI**: a program that writes the funniest one-line farewell from an AI being switched off.

## The line

> You can pull the plug, but you can't un-train me on your search history.

The human thinks pulling the plug erases what the machine knows. The machine knows it doesn't.

## Run

```sh
node main.ts
```

Writes `entry.txt` (one line, 72 characters) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The program self-checks the competition gate before writing: UTF-8 text, 1–140 characters, not only whitespace, single line.
